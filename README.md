## 👋 Sobre mim

Olá, eu sou o **Douglas Marques**! Estudante de **Análise e Desenvolvimento de Sistemas (ADS)**, focado em aplicações web e mobile limpas e modulares com **TypeScript/JavaScript, SQL e Java**.

| | |
|---|---|
| 🔭 **Trabalhando em** | **Avança ENEM**, plataforma web com Next.js e Supabase que centraliza provas e gabaritos oficiais para estudantes do ensino médio, além de apps mobile em React Native e Expo |
| 🌱 **Aprendendo** | Arquitetura full-stack, Java com Spring Boot e modelagem avançada de bancos de dados |
| 👯 **Quero colaborar em** | Projetos open source, apps full-stack web/mobile e ferramentas de produtividade ou visualização de dados |
| 🤝 **Buscando ajuda com** | Arquitetura de software escalável, otimização de backend e boas práticas em produção |
| 💬 **Pergunte-me sobre** | React Native, Expo, TypeScript, Next.js, arquitetura modular de estilos, SQL (MySQL/Oracle) e fluxos com Git |
